# ambre-trame/schema/readings.txt  The frozen schema readings (`SCHEMA-017`).
#
# One section per `SCHEMA_VERSION`, each holding what a build stores and what
# it reads back, for every value of the shape belt's workbook. A line reads
# `path = stored => reading`. The path collapses ids as `shapes.txt` does. The
# reading is taken by a second workbook that reopened the first one's
# snapshot, in absolute units: px, pt, `#rrggbb`, one-based rows and columns.
#
# Written by `logic::schema_reading`, which fails when a build stores or reads
# a value otherwise than the section frozen for its version. A reading that
# moves needs a raised `SCHEMA_VERSION` and a new section below, never an edit
# to the section above: a section is the record of what that version meant.
