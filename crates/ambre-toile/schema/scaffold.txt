# ambre-toile/schema/scaffold.txt  The frozen scaffolding identities (`AUTHOR-024`).
#
# One section per `SCHEMA_VERSION`, each holding, as hex, the peer identity the
# scaffolding of a new board is written under. The identity hashes the
# scaffolding's bytes, so every build of one version must write the same one: a
# delta that waits on a scaffolding change its reader never wrote never applies.
#
# Read by `logic::state::schema_shape`, which fails when a build's scaffolding
# leaves the section frozen for its version. A scaffolding that moves needs a
# raised `SCHEMA_VERSION` and a new section below, never an edit to the section
# above.
