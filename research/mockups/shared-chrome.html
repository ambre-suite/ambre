Ambre shared chrome

Non-normative. Snapshot of a design discussion held on 2026-11-21. The decisions it led to live in the shell spec (specs/1-Foundations/ambre-spec-shell.md) and the application specs; where this page and a spec disagree, the spec wins. This file is frozen: it is not updated when the specs change.

One grammar for Prose, Trame and Toile. Each action has one place, chosen by what it touches: the view, the document, the file or the account. Everything is clickable. Ctrl K opens the command palette, and a right click on the content (or Shift F10) opens the context menu. Hovering an icon, or reaching it with the keyboard, shows its name and its shortcut.

What is contextual repeats the panel. The context panel, the context bar and the context menu show the commands of the context panel; the panel is their one home. Only the clipboard (cut, copy, paste) has its home in the context menu.

What goes away

  • Docked toolbar: replaced by the context bar and the panel.
  • Drop-down menus of Toile: replaced by the command palette.
  • Vertical tool palette of Toile: becomes the creation bar, shared by the three apps.
  • Hamburger menu: the Ambre ▾ logo plays that role.

Three rules for the phone

  • One panel carries the formatting: it rises from the bottom and replaces the keyboard.
  • No action exists on hover alone.
  • On text, the context bar leaves cut, copy and paste to the system menu; on a cell or a shape, a long press opens the context menu as a bottom sheet.
