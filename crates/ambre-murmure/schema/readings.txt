# ambre-murmure/schema/readings.txt  The frozen schema readings (`SCHEMA-017`).
#
# One section per `SCHEMA_VERSION`, each holding what a build stores and what
# it reads back, for every value of the shape belt's channel and space. A line
# reads `path = stored => reading`. The path collapses ids and list positions
# as `shapes.txt` does, and an identifier the engine mints stores as `{uuid}`.
# The reading is taken by a second peer that reopened the first one's
# snapshots, in absolute units: milliseconds, bytes, one-based ranks.
#
# Written by `schema_reading`, which fails when a build stores or reads a
# value otherwise than the section frozen for its version. A reading that
# moves needs a raised `SCHEMA_VERSION` and a new section below, never an edit
# to the section above: a section is the record of what that version meant.
