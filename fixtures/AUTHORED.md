# INTEROP FIXTURES AUTHORED IN THIS REPOSITORY

Each input file a converter test reads that this repository wrote, one row per file. A file copied
from another project has its row in `fixtures/THIRD_PARTY.md` instead. The rules are
`ambre-spec-interop.md section 1.4`, and `just fixture-provenance` holds them.

`Origin` is `hand-written`, or `generated by` and the committed script that writes the file. `Holds`
says what the file is, so a reviewer can tell it from a real document (`INTEROP-025`).
